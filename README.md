# InventoryManager
Un petit outil simple et efficace pour gérer un inventaire de produits, développé en Python. Ce projet m’a permis de pratiquer la manipulation de fichiers, les structures de données, et la création d’une interface utilisateur en ligne de commande.

## 🚀 Fonctionnalités

- Ajouter un produit avec nom, quantité et prix
- Supprimer ou modifier un produit existant
- Rechercher un produit par nom
- Afficher l’inventaire complet
- Sauvegarde automatique dans un fichier `.csv`
- Possibilté d'exporter le fichier en json

---

## 🛠️ Technologies utilisées

- Python 3
- `csv` pour la gestion des données
 - Programmation orientée objet
- Interface utilisateur en ligne de commande
